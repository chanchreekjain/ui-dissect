Privacy Policy for UI Dissect

Last updated: September 5, 2026

UI Dissect (“the extension”, “we”, “us”) is an open-source browser developer tool designed to inspect and extract visual styling code on hover. We are committed to absolute user privacy and data security.

1. Zero Data Collection

UI Dissect does not collect, record, transmit, sell, or monitor any personal data, user credentials, browsing history, keystrokes, or website contents.

2. 100% Client-Side Execution

All DOM parsing, CSS style extraction, and code generation algorithms execute strictly in-memory on your local machine. No information ever leaves your local browser session.

3. Local Storage Usage

The extension uses Chrome’s local storage API (chrome.storage.local) exclusively to store user-defined interface preferences, such as your default preferred export format (Tailwind CSS, Scoped CSS, or React). This preference data stays on your local device and is never synchronized to external servers.

4. Minimal Permissions Justification

  • activeTab: Required solely to read element dimensions and styles on the specific tab you choose to inspect.
  • scripting: Used only to inject the content script into pre-existing tabs on demand.
  • storage: Required to persist local tool preferences.

5. Third-Party Services & Telemetry

UI Dissect contains zero third-party trackers, external CDNs, advertising networks, or analytics tools.

6. Source Code & Contact

UI Dissect is fully open-source. You can inspect the source code or open questions on GitHub at: github.com/chanchreekjain/ui-dissect.
